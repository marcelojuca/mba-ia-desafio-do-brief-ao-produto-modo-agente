`create_event nome cap preço` = `POST /organizer/events` (name, startsAt=2026-12-15T20:00, venue, capacity, price) com o jar de A, retornando o id do `Location`;
`publish E` = `POST /organizer/events/E/publish`;
`buy jar E cartão` = `curl -w '%{http_code} %{time_total}s' -b jar --data-urlencode cardNumber=... $WEB/events/E/purchase`;
`art`/`mt` extraem, como texto, o `<article data-event-id>` da vitrine e as linhas `<tr data-ticket-code>` de `/my-tickets`.
